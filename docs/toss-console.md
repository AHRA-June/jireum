## 어떤 앱을 만들고 싶나요? (앱 설명)

> 사고 싶은 물건과 가격을 넣으면 진짜 회사 서류 같은 '지름 결의서'가 만들어지고,
> 심사를 거쳐 승인/조건부 승인/부결 도장이 쾅 찍힌 판정서가 나오는, 그게 전부인
> 하찮은 앱이에요. 하지만 "부결: 이번 달 4번째 지름" 도장이 찍히는 순간 피식하게
> 되고, 친구에게 판정서를 보내며 서로의 지름을 결재해 주게 되죠. 소비 앞에서 늘
> 망설이는 우리 모두가 타깃이에요. 실제 금융 상품과는 무관한 패러디이며, 면책
> 문구를 항상 표시합니다.

## 연동 정보

- `appName`은 `apps-in-toss.config.ts`와 반드시 일치해야 함 (`jireumform`)
- 서비스 도메인: `https://jireumform.web.tossmini.com`
- QR 테스트 도메인: `https://jireumform.private-web.tossmini.com`
- 배포: 콘솔에서 API 키 발급 → `npx ait token add` → `npm run build && npm run deploy`

## 유의사항

- 리워드성 표현 금지, 금융 상품·대출 연상 표현은 패러디임이 명확한 선까지만
- 면책 문구("본 판정은 법적 효력이 없으며, 지름은 본인 책임입니다") 하단 고정 표시
